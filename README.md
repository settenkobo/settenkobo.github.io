# 接点工房 — 電気系保全 故障診断トレーナー

機械保全技能検定（電気系保全作業）実技の**課題2**、すなわち有接点シーケンス回路の
点検・修復を練習するための学習ソフトです。断線・誤配線・不良リレー・不良タイマを
含む制御盤から原因を切り分け、修復した盤を実際に動作させて自動判定します。
